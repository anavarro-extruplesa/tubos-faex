Carpeta de guardado del Excel

El archivo Incidencias_TUBO_FAEX.xlsx se escribe y actualiza automáticamente cada vez que registras algo. Conecta una sola vez la carpeta compartida y la app la recordará.

Z:\FABRICA\APP TUBO FAEX
Carpeta no conectada todavía.

Umbral de cambio

Número de tubos por terraja antes de tener que cambiarla.

Cómo funciona

1. Pulsa Conectar carpeta y elige Z:\FABRICA\APP TUBO FAEX. El navegador te pedirá permiso para escribir en ella; pulsa "Permitir".

2. A partir de ahí, cada vez que añadas producción, registres un cambio de terrajas o guardes una incidencia, el archivo Incidencias_TUBO_FAEX.xlsx se reescribe solo en la carpeta. Vosotros podéis abrirlo desde vuestros equipos cuando queráis para ver el progreso.

3. Los datos también quedan guardados en este ordenador, así que aunque te quedes sin red la app sigue funcionando.

Borrar datos del ordenador

Esta acción borra el conteo, las terrajas y las incidencias guardadas en este ordenador. El Excel ya guardado en la carpeta no se ve afectado.

Conecta la carpeta compartida

Para que el Excel se actualice solo, la primera vez tienes que elegir la carpeta donde quieres guardarlo.

Z:\FABRICA\APP TUBO FAEX

Pulsa el botón y selecciona esa carpeta cuando se abra el explorador. El navegador te pedirá permiso para escribir; pulsa Permitir.

Editar producción histórica

Indica cuántos tubos malos hubo en cada registro. El total de cada día no cambia (para no descuadrar el contador de cambio de terrajas); los tubos buenos se recalculan solos.
